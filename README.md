# Interactive Student Portal Console System

## Project Description

This project is a console-based Student Management System developed using Java 21.

The application allows users to add, display, search, edit, and delete student records.

## Features

- Add Student
- Display Students
- Search Student
- Edit Student
- Delete Student
- Exit the application

## Technologies Used

- Java 21
- Object-Oriented Programming
- Java Collections Framework
- ArrayList
- Java Streams API

## OOP Concepts Used

- Class and Objects
- Encapsulation
- Constructor
- Methods
- Getters and Setters

## Collection Framework

ArrayList is used to store student records in the application.

## Streams API

Java Streams API is used to search and filter student records.

## How to Run

1. Open the project in Eclipse.
2. Make sure Java 21 is selected.
3. Open StudentPortal.java.
4. Right-click and select Run As → Java Application.
5. Use the menu displayed in the Console.

## Student Operations

The application provides the following operations:

1. Add Student
2. Display Students
3. Search Student
4. Edit Student
5. Delete Student
6. Exit

## Conclusion

The Interactive Student Portal demonstrates the use of Java 21, OOP concepts, Collections, and Streams API to create a simple student management application.
